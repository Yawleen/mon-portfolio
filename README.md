# Portfolio - Yolène Constable

Portfolio personnel développé avec React et Vite afin de présenter mon profil, mes compétences, mes projets et mes informations de contact.

🌐 Site en ligne : https://yoleneconstable.dev/

## 🚀 Technologies utilisées

- React
- Vite
- JavaScript
- CSS
- GitHub Pages
- Domaine personnalisé

## 📦 Installation du projet

Cloner le repository :

```bash
git clone https://github.com/Yawleen/mon-portfolio.git
```

Installer les dépendances :

```bash
npm install
```

Lancer le projet en local :

```bash
npm run dev
```

## 🛠️ Build du projet

Pour générer la version de production :

```bash
npm run build
```

## 🌍 Déploiement

Le projet est déployé avec GitHub Pages.

```bash
npm run deploy
```

Le fichier `CNAME` permet de conserver le domaine personnalisé :

```txt
yoleneconstable.dev
```
